# Skills do vibe-workspace

**Padrão de nomenclatura:** prefixo por camada (kebab-case)
- **front-** — frontend (ex.: `/front-brand-guidelines`)
- **back-** — backend (ex.: `/back-dotnet-guidelines`)
- **workspace** — sem prefixo para contrato/orquestração

**Skills:**
 - **front-brand-guidelines**
 - **back-dotnet-guidelines** — diretrizes técnicas para projetos .NET (C# / ASP.NET Core)
- **vibe-workspace-contract** — contrato do workspace (make, repos, quality gate)
